# MASAE Delivery Tracker - Local Setup & Dependency Requirements
# ==============================================================================
# Note: This is a Node.js / React TypeScript project powered by Vite.
# Standard installation uses npm or bun.
# ==============================================================================

# Prerequisites
# --------------
# Node.js: >= 18.0.0
# npm: >= 9.0.0 (or bun / yarn / pnpm)

# Quick Local Setup Commands:
# ---------------------------
# 1. Install dependencies:
#    npm install
#
# 2. Run local development server (starts on http://localhost:3000 or http://localhost:5173):
#    npm run dev
#
# 3. Build for production:
#    npm run build
#
# 4. Preview production build:
#    npm run preview

# ==============================================================================
# Project Dependencies
# ==============================================================================
# Note: All dependencies are managed via package.json using Node.js / npm.
# Do NOT run 'pip install -r requirements.txt'.
#
# Render.com Deployment Setup:
# ----------------------------
# 1. Select 'Static Site' or 'Node Web Service' on Render.
# 2. Build Command: npm install && npm run build
# 3. Publish Directory: dist (for Static Site) or Start Command: npm run preview
# ==============================================================================
