# Prerequisites
# --------------
# Node.js: >= 18.0.0
# npm: >= 9.0.0 (or bun / yarn / pnpm)

# Quick Local Setup Commands:
# ---------------------------
# 1. Install dependencies:
#    npm install
#
# 2. Run local development server (starts on http://localhost:3000 or http://localhost:5173):
#    npm run dev
#
# 3. Build for production:
#    npm run build
#
# 4. Preview production build:
#    npm run preview
